# Project Statement

## Problem Statement
Cybersecurity incidents need to be recorded, assigned, tracked, searched, and reported in an organized manner. Maintaining such information manually can make it difficult to track incident status, severity, and responsible investigators.

## Scope
The Cyber Incident Management System is a command-line Java application that manages incident records for a small organization. It supports incident registration, searching, filtering, investigator assignment, status updates, reporting, and local file persistence.

## Target Users
- Security students learning incident management
- Small security teams
- System administrators
- Academic demonstration/evaluation users

## High-Level Features
1. Incident registration
2. Incident listing and search
3. Severity and status management
4. Investigator assignment
5. Report generation
6. File-based data persistence
7. Input validation and exception handling
